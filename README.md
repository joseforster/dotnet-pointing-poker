# Pointing Poker

A simple and modern planning poker web app for agile teams.  
Built with ASP.NET Core, SignalR, and Bootstrap.

---

## 🚀 Features

- Real-time communication using SignalR  
- Create and join sessions  
- Select cards and reveal results  
- Minimalist UI
